# 梁文峰 / 梁文谷 峰谷价提示器

> 一个挂在 DeepSeek Harness 侧边栏底部的峰谷价提示器。官方说峰就峰，说谷就谷，绝不瞎编——瞎编的只有那张脸。

DeepSeek 的 API 分峰谷价，你的侧边栏凭什么不分？

别人在侧边栏看会话，你在侧边栏看梁文峰今天帅不帅。官方时段一到，它自己翻脸；你付的是电费，他涨的是修为。

```
[头像]  梁文谷  省钱中
        1小时14分57秒后进入梁文峰
        ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁  ← 线性进度条
```

## 这玩意儿到底干嘛的

- **谷**（空闲时段）：`省钱中`，头像从「梁祖」一档档退回「普通人」；
- **峰**（高峰时段）：`挨宰中`，头像从「普通人」一档档修成「梁祖」；
- 31 档，一秒一秒往前挪，切换点前后图像连续，不会跳；
- 侧边栏收成 56px 图标条时只留头像，像个门神；
- 不联网、不读会话、不改模型、不改账单——它只会在你耳边小声说：**快 18:00 了**。

## 它怎么知道现在是峰还是谷

抄的官方作业（[DeepSeek 定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)）：

> 北京时间周一至周五（不含中国法定节假日）**9:00–12:00、14:00–18:00** 为高峰时段；其余时段，包括**周末及中国法定节假日全天**均为空闲时段。

节假日表内置了 2026 年（[国办发明电〔2025〕7号](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)）和 2027-01-01；2027 年放假安排公布后记得补，不然元旦那天它会一本正经地骗你。

## 装它

本包是个 DSH bundle（`dsh.bundle.patch` + `dsh.client`），Host 半是个空壳，界面全在 `client.js`，没有构建步骤。

1. 把仓库克隆到本机；
2. 用 DSH 的插件管理器（`plugin_manager` / Plugins 页的本地安装）指向这个目录；
3. 侧边栏底部就会多出这条小横条。

不用重启 Host；换机器重新装一次就行。

## 想改？

`client.js` 顶部两个常量，改完刷新即可：

- `PEAK_WINDOWS`：高峰时段（分钟数）；
- `HOLIDAYS`：法定节假日（`YYYY-MM-DD`，只填工作日的那些天）。

时区固定按北京时间（UTC+8）算，不用管你在哪。

## 副作用

- 13:59 会莫名焦虑；
- 可能为了看「梁祖」故意拖到 17:59；
- 可能开始研究滑动变阻器的接线柱；
- 不会让你的 token 变便宜，一分都不会。
